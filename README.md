# TipSplitter

TipSplitter is a user-friendly app designed to simplify the process of splitting bills and calculating tips. Whether you're dining out with friends or splitting costs in any group setting, TipSplitter helps you ensure fairness and accuracy.

## Core Features

-   **Bill Input**: Easily input the total bill amount, desired tip percentage, and the number of people splitting the bill.
-   **Calculation Display**: Instantly view the tip amount, the total bill amount (including the tip), and the individual amount each person owes.
-   **Rounding**: Optionally round up the final amounts for convenience.

## Style Guidelines

-   **Primary Color**: Light pink (#FFB6C1) to provide a soft and welcoming feel.
-   **Secondary Color**: Lavender (#E6E6FA) for a calming and complementary contrast.
-   **Accent**: Hot pink (#FF69B4) for interactive elements, making them stand out.
-   **Layout**: Clean and intuitive design with clear sections to distinguish between input fields and calculation results.
-   **Icons**: Simple, outline-style icons to represent key elements such as the bill, tip, and people.
